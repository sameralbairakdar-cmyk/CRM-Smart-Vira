# Product Overview

## Purpose

CRM Smart Vira helps service businesses manage repair orders, inventory, staff responsibilities, and customer handovers from a single interface. Its neutral branding and configurable workspace name allow it to be reused across different companies and service industries.

## Main Capabilities

### Operations Dashboard

The dashboard summarizes active orders, ready jobs, low-stock items, and out-of-stock items. It also shows the permissions currently available to the signed-in role.

### Service-Order Management

Each order stores the customer, contact information, serviced item, serial or reference number, reported issue, priority, technician, status, services, prices, notes, and update history.

### Inventory Management

Inventory records include item name, SKU, category, quantity, minimum stock level, storage location, and price. Financial inventory value remains restricted to administrators.

### Configurable Identity

The workspace name, default language, and currency can be adapted without changing the product's source code.

## Intended Users

- Repair centers
- Electronics and device workshops
- General technical service teams
- Internal maintenance departments
- Small and medium service businesses

## Privacy and Distribution

The product source code is private. Public materials are limited to feature descriptions, user documentation, and interface screenshots.
