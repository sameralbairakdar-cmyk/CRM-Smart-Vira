# Roles and Permissions

## Administrator

Administrators have complete operational and configuration access.

- Create, edit, and delete all records
- Assign technicians and edit all service orders
- Manage users, roles, and permissions
- Manage inventory and view financial values
- Access reports, exports, and audit information
- Configure business identity, language, currency, and printing

## Technician

Technicians have the tools required to complete assigned work without access to system administration.

- Open and edit assigned service orders
- Update diagnosis, issue, status, and priority
- Add technical notes and work history
- Add services and prices
- Mark services as completed
- Record consumed inventory parts
- Mark completed orders as ready
- View relevant customer and item information

## Employee

Employees support intake, customer service, and handover operations.

- Create and view service orders
- Search orders, inventory, and serial/reference numbers
- View available stock quantities
- Print intake and delivery documents
- Mark ready orders as delivered
- No access to inventory values, user management, or system configuration

## Permission Principle

Every role receives only the access required for its daily tasks. Sensitive administration and financial information remain limited to administrators.
