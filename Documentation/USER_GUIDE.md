# User Guide

## Navigation

The left navigation provides access to Overview, Service Orders, Inventory, Users and Roles, and System Settings. Administrative sections are visible only to administrators.

## Working with Service Orders

1. Open **Service Orders**.
2. Search by order number, customer, serviced item, or serial/reference number.
3. Select **Open** to display the order workspace.
4. Review the customer, item, reported issue, priority, technician, and current status.
5. Add services and their prices when additional work is required.
6. Mark completed service lines.
7. Add a technical note describing diagnosis, work performed, or an internal update.
8. Change the status as the job progresses.
9. Mark the order as **Ready** after completion.
10. Print the order when a physical record is needed.

## Working with Inventory

Administrators and technicians can record stock movements. Technicians use the decrement action when a part is consumed during a service job. Employees can search and view quantities but cannot change stock or view financial totals.

## Changing the Workspace Identity

Administrators can open **System Settings**, enter a new workspace name, select a default language and currency, and save the configuration. This makes the same system suitable for another company without rebranding the application code.

## Status Definitions

| Status | Meaning |
| --- | --- |
| New | The order has been created but work has not started. |
| Diagnosis | The item is being inspected. |
| In Progress | Technical work is underway. |
| Waiting for Part | Work is paused until a required part arrives. |
| Ready | Work is complete and the item can be collected. |
| Delivered | The completed item has been handed to the customer. |
