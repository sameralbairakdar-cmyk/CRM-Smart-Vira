# Operational Workflows

## Order Lifecycle

1. An employee or administrator creates the order during intake.
2. An administrator assigns a technician and priority.
3. The technician reviews the reported issue and begins diagnosis.
4. The technician records notes, services, and consumed parts.
5. If a part is unavailable, the status changes to **Waiting for Part**.
6. After all work is completed, the technician marks the order **Ready**.
7. The employee completes the handover and marks the order **Delivered**.

## Technician Update Workflow

1. Open an assigned order.
2. Confirm the serial/reference number and reported issue.
3. Set the current priority and status.
4. Add or complete service lines.
5. Record an internal technical note.
6. Consume installed parts from inventory.
7. Mark the order ready after final verification.

## Inventory Workflow

1. Administrators create inventory items and define minimum levels.
2. Incoming stock increases the available quantity.
3. Technicians decrease stock when parts are installed.
4. The dashboard highlights low and unavailable items.
5. Administrators review the inventory value and arrange replenishment.

## Reuse for Another Business

1. Open System Settings.
2. Replace the workspace name with the new business identity.
3. Select the preferred language and currency.
4. Configure users and their roles.
5. Add the new company's inventory categories and services.
